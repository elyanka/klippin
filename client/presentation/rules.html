Rules · Scope#
Global rules

Global rules

Apply to the clipper app and the website. When a screen and this page disagree, this page wins. The brand guide governs brand expression (logo, voice, marketing); fonts follow these rules.

Scope

Visual only

  • UX and flows do not change. We change how things look: colour, type, spacing, components, chip styling and copy.
  • Renamings (e.g. Locked → Private) are optional copy, never a flow change.
  • Nothing goes into live screens until the client approves.

One theme

  • Dark mode only. There are no light tokens for now.
  • Design with semantic tokens (bg/, text/, border/, brand/, status/), never with primitives or raw hex.
  • Shared by app and web. Web adds base-deep/deepest, surface-low/glass and the display hero/h1/stat, body lead/web and eyebrow styles.
Rules · Status logic#

Status logic

One colour logic for every entity. Lifecycle = CAPS chip: coloured 12px icon + label on a subtle fill. Membership = coloured 16px icon + sentence case in a neutral tag. Both use radius/sm (8). PAID is the only filled chip.

Contexts reuse the lifecycle colours with their own label, as real variants of the status chip (no free-text labels). Labels are always CAPS. A new context gets a new variant here first.

Icon: dot = live, clock = scheduled / waiting / pending, hourglass = in review, flag = finished, archive, check = paid, cross = rejected, block = cancelled, link = connected, seal = verified, star = default.

Membership tags · 28px · radius/sm

Joined Pending Open Private Applied

Neutral bg/tint tag (not a pill: radius/sm, like chips); the icon carries the colour (green joined and applied, amber pending, white open, grey private). Membership is factory-level, not campaign-level; Applied marks a campaign the clipper applied to (factory seen from Analytics).

Progress

  • Brand fill = money and goals (budget, earnings, prize).
  • Neutral fill = time and finished things. Exception: media playback (the video scrubber) is orange, because the user controls it.

Format & wording

  • Format: euro prefix, comma thousands, dot decimals: €1,000 · €4,812.60. Never $, never a suffix.
  • Rate wording “€2.40 / 1M views”. Do not use the term RPM in the app.
  • Money figures in Space Grotesk Bold. Never green for money.
  • Leaderboard: other rows show amounts in white; the “you” row is a brand tint (surface + orange 28%→6%) with a 1px orange border and an orange amount, so only your amount is orange.
Rules · Time#

Time

Relative dates

  • Just now · 5m ago · 3h ago · 2d ago (up to 7 days), then 12.10 (12.10.2025 for another year).
  • Chat bubbles keep clock time.
  • Absolute dates by context: data rows 12.10.2025 · list group separators “11 June 2025” · chart axes “Sep 12”.

Countdown tags

  • Countdown tags: “3h left”, “Starts in 3h”, “Ended 12.10”. Same shape as chips (radius/sm), sentence case; in the kit it is the soft pill inside the campaign card.
Rules · Buttons & text on orange#

Buttons & text on orange

Buttons · type × state

DefaultApp + web PressedApp + web DisabledApp + web HoverWeb only · pointer FocusWeb only · keyboard Primary L · 44 Primary M · 36 Secondary L · 44 Secondary M · 36 Text L · 32 Text M · 28

Sizes

  • Sizes: L 44px tall, 20px side padding, radius/md (12), label 18px semibold · M 36px, 16px padding, radius/sm (8), label 14px semibold · icon gap 8px, icons 20 (L) / 16 (M).
  • Text buttons: same label sizes as L / M in brand orange, 8px side padding, radius/sm box (32 / 28px). The touch target is always at least 44px tall, even when the visual box is smaller.

States

  • Pressed (agreed): primary +18% black · secondary bg/tint-strong · text brand tint 15%. Disabled: whole button at 40% opacity, all types. The app has no hover or focus (touch).
  • Hover (web): primary switches to gradient/vibrant-orange with a warm glow (0 4 16, orange 35%) · secondary bg/tint-strong + 1px border/glass · text brand tint at 8%.
  • Focus (web, :focus-visible): primary 2px white ring with a 2px dark gap · secondary 2px orange ring with a 2px gap · text 2px orange ring tight to its box (no gap).

Destructive & accessibility

  • Destructive actions: red label and icon in menus and rows. The confirmation that commits them (leave, delete, cancel) uses Danger soft (red-tinted fill, red label), never the orange primary, so it differs from orange by weight, not only by hue. Solid Danger is reserved for rare, irreversible bulk actions.
  • Accessibility exception (deliberate, agreed): white labels on the primary gradient are 2.9–3.2:1 and fail WCAG AA (4.5:1). Kept for the brand look; never reuse white text on orange anywhere else.

Rules · Depth, icons & accessibility#

Depth, icons & accessibility

Elevation (4 levels)

  • 0 · page: bg/base (app), bg/base-deep (web).
  • 1 · containers: bg/surface + border/default.
  • 2 · elements on any surface: bg/tint, pressed bg/tint-strong.
  • 3 · overlays: bg/raised + border/default + elevation/overlay, over bg/scrim.

Icons & accessibility

  • Icon sizes: 20 in L buttons, icon buttons and menus · 32 in the bottom nav · 16 in M buttons, membership tags and inline text · 12 in lifecycle chips.
  • White icons on photos get elevation/icon-on-media and a bottom fade.
  • Text never below 12px, except label/eyebrow (11px CAPS, web only). text/tertiary is the lightest text allowed: ≥4.5:1 on bg/base and bg/surface. On raised surfaces (bg/raised, bg/raised-strong) meta text uses text/secondary. text/disabled only for disabled states.
