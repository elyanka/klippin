Client landing · What changed#
TokensEvery colour, gradient, radius and spacing value reads the kit's Client mode (tokens v2.1.0, data-system="client"). Only the section glows, glass surfaces and shadows stay page-only: they are not in the kit yet.
EffectsThe hero wave, the network mechanism and the globe are the live page's own scripts, running as they do on partners.klippin.io.
ColourErrors and success use the shared kit values (#FF5A6E, #36B756). Card and button hairlines use border/glass (white 12%, was 15%). Footer rules use border/default.
TypeOverpass for headings and metrics, Manrope for body, live web scale. Paragraphs at line-height 1.6 (was 1.3).
ShapeRadius and spacing snap to the kit scales: 6 and 10 to 8 and 12, 14 and 20 to 16; 15, 18, 22, 25, 30, 38, 50, 72 to the nearest step. Buttons use radius/button (pill) and the Client hover glow.

The hero headline is set in Manrope on the live page, not Overpass. Kept as live; the token still says Overpass. The contact form never submits on this copy.

Landing page · What changed#
Built from the kitEvery piece on the updated page is a kit component: web nav bar, eyebrow, store badge, perk, kit phone mockup, web stat, web section header, step card, earnings track, web note, FAQ item, web footer. The page’s own CSS only places them (grids, widths, spacing).
Phone mockupThe kit phone mockup: balance card, section header, filter chips, campaign cards with LIVE / UPCOMING chips, bottom nav. Same screen as the app mockups.
TypeInter for UI text, Space Grotesk for headlines, stats and money, Plus Jakarta ExtraBold only for eyebrows. On phones the display sizes step down (kit rule “web type below 760px”).
MoneyEuros, same figures: €12,000+, €4,812.60, €300 to €1,000, €12K+. Amounts in brand orange.
Buttons“Get the app” is the kit Primary M (L in the mobile menu), “View Campaigns” the kit Secondary L, on one row with the store badges (kit store badge M, same 44px height). Store badges stay as platform artwork.
LayoutHow it works and FAQ sit on a lighter band (kit web band). Soft brand glow behind the hero and the closing call to action (kit web glow). Phone mockup larger and tilted 4°, like the live page. The three earnings tiers share one line that warms up toward Advanced (kit earnings track). The earnings note sits under a divider instead of a box, closing line larger (kit web note, Divider).
DetailsStats share one row with hairline dividers (kit web stats row), also on phones. Headings and leads wrap in balanced lines. Step icons on a soft brand tint instead of an orange outline. Tier descriptions and FAQ answers use the web body text (15/1.6). FAQ is an open list with hairlines and plain orange plus/minus (kit faq item · web). On phones the perks stack in a column.
