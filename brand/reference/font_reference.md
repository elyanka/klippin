# Klippin font reference

Families and weights per system, as set in `klippin_tokens.json` (v3.0.0). Load only these weights.

| System | Typeface | Role | Weights | Family page |
| --- | --- | --- | --- | --- |
| Client | Overpass | Display, headings, metrics | 600, 800 | [Overpass on Google Fonts](https://fonts.google.com/specimen/Overpass) |
| Client | Manrope | Body, UI, forms, landing hero | 400, 600 | [Manrope on Google Fonts](https://fonts.google.com/specimen/Manrope) |
| Clipper | Space Grotesk | Display, headlines, money | 700 | [Space Grotesk on Google Fonts](https://fonts.google.com/specimen/Space+Grotesk) |
| Clipper | Inter | Body and all UI | 400, 500, 600, 700 | [Inter on Google Fonts](https://fonts.google.com/specimen/Inter) |
| Clipper | Plus Jakarta Sans | Web eyebrows only | 800 | [Plus Jakarta Sans on Google Fonts](https://fonts.google.com/specimen/Plus+Jakarta+Sans) |

The Klippin wordmark is vector artwork, not one of these fonts. Always use the supplied logo files.

## Web setup

`font_styles.css` loads every family above from Google Fonts. For production, self-host the files from the family pages and keep the licence that comes with them. No font files are included in this pack.

Stylesheet URL:

https://fonts.googleapis.com/css2?family=Overpass:wght@600;800&family=Manrope:wght@400;600&family=Space+Grotesk:wght@700&family=Inter:wght@400;500;600;700&family=Plus+Jakarta+Sans:wght@800&display=swap
